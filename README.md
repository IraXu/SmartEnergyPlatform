## 五、已覆盖的交互点

### 5.1 注册（P-02）

- 单页分步：验证账号 → 设置密码 → 企业信息（**固定三步**，步骤指示器可回退）。
- 账号输入框自动识别手机号与邮箱：手机号默认 +86 中国并可切换国际区号，输入含 @ 的内容自动切换为邮箱输入。
- 验证码：6 位数字、5 分钟有效、60 秒冷却、单日上限 10 次；冷却时间按账号标识独立计算。
- 密码强度实时反馈（弱/中/强），仅「中」及以上可提交；两次输入一致性校验。
- 企业信息：企业名称、所属行业、所在地区（省/市联动）、联系人姓名、联系人电话必填，联系人职务选填；手机号注册时联系人电话自动带入注册手机号并只读。
- 协议勾选校验；离开注册流程前二次确认。
- **注册来源分流**：步骤一提交后按账号来源判定——账号已停用 → 拦截；已从注册页自助注册过 → 拦截并提供「去登录」；仅被企业新增过（本人从未自助注册）→ 放行并提示将为其创建新企业，照常进入密码步骤由本人设置密码；全新账号正常进入。**「加入企业」不在注册页承载**，已移至企业成员页新增成员。

### 5.2 登录（P-01）

- 密码登录 / 验证码登录页签切换，切换保留账号输入、清空验证码与错误提示。
- 账号输入框自动识别手机号与邮箱，不提供独立的账号类型切换控件。
- 手机号支持选择国际区号（默认 +86 中国），支持按国家/地区中文名、英文名、区号、ISO 代码搜索。
- 连续失败 3 次后出现图形验证码且为必填，点击图片可刷新。
- 连续失败 5 次锁定账号 15 分钟，锁定期间展示剩余时间倒计时并禁用密码登录。
- 锁定期内使用验证码登录成功即解除锁定。
- 账号停用、账号未注册、验证码错误/失效等异常提示。
- 记住登录状态（7 天）与默认登录态（2 小时无操作失效）。
- **登录后进入决策**：账号仅归属 1 家企业时直接进入；归属多家企业时，有最近登录记录则自动进入该企业，否则进入「选择登录企业」。

### 5.3 选择登录企业（P-06）

- 企业列表：每项展示**企业徽标**（企业已上传 Logo 时展示 Logo，未上传或删除后回退企业名称首字渐变徽标，44×44px 圆角 6px）、企业名称、**当前账号在该企业下的角色**、企业标识与「最近登录」标签；选中项以主色描边与浅底标识。
- 默认选中最近登录企业（无记录时选中列表首项）。
- 「记住选择，下次自动登录」勾选框：**默认不勾选**；勾选后进入即写入自动进入依据，下次登录自动进入该企业、不再展示本页；未勾选则下次登录仍展示本页。
- 核心定义：最近登录 = 该账号最近一次「成功选择某企业并进入系统」的时间；**「最近登录」（用于打标签与默认选中）与「记住选择」（用于下次自动进入）为两份独立记录**，因此未勾选时仍能看到「最近登录」标签。
- 「返回登录」可回到登录页重新开始（先结束未选定企业的登录态再跳转）。

### 5.4 切换企业（顶栏）

- 企业名称由顶栏左侧移至右侧账号信息区左侧，展示为可点击控件（**企业徽标**（Logo 优先，未上传回退企业名称首字，20×20px 圆角 4px）+ 名称 + 箭头）；控件带**常驻浅边框与极淡投影**，悬停转主题绿、展开叠加主题绿实边与外发光聚焦环。
- 点击展开该账号归属的全部企业与在该企业下的角色（角色以**绿色标签**呈现，每项前置 24×24px 企业徽标），当前企业以**左侧绿色色条 + 主色企业名**标识；点击其他企业即切换。
- 已停用归属不出现在切换浮层中。
- 切换后按「重新进入系统」处理：刷新当前页面数据与顶栏信息，停留当前页面，并更新最近登录企业。

### 5.5 忘记密码（P-03）

- 两步结构：验证账号 → 设置新密码。
- 账号输入同登录页，自动识别手机号与邮箱，支持国际区号。
- 发送结果统一提示「若该手机号/邮箱已注册，验证码已发送」，不暴露账号是否存在。
- 新密码不得与原密码相同；重置前二次确认并说明影响范围。
- 重置成功后解除账号锁定，跳转登录页并提示使用新密码登录。

### 5.6 会话与退出（P-04 / P-05）

- 注册成功结果页回显企业信息与当前角色，3 秒后自动进入平台首页。
- 平台首页展示企业、账号（脱敏）与角色信息，顶栏与退出登录由 `AdminLayout` 统一承载。
- 退出登录二次确认，文案说明「其他设备的登录状态不受影响」。
- 退出后浏览器回退无法进入已登录页面。

### 5.7 后台导航（P-05 及后续模块共用）
- 两级导航：一级为左侧图标窄栏（宽 100px，图标在上文字在下），二级为与一级栏并排的通高导航列（宽 200px）。
- 一级导航本期挂载「工作台」「系统管理」（原「组织与用户」已随模块二取消移除）；当前模块与展开项以浅底 `#ecf4f3` 高亮。
- 「系统管理」固定在一级导航栏底部，与业务域以 1px 分割线隔离；其下已挂载 6 个二级菜单项：组织架构、企业成员、角色管理、系统日志、企业中心、品牌设置。
- 配色与顶栏统一：一级栏白底、二级列与选中一级项同为 `#ecf4f3`、二级当前项为白色块；接缝处用内凹圆角（`--nav-fillet`，当前 14px）抹圆直角，两级连成一体，无分割线或色差。
- 二级导航列为通高整列，与一级栏并排（不浮于内容之上），展开后内容区可用宽度相应减少；内容超出时列内滚动。
- 二级导航仅支持点击展开（不支持悬停展开），可通过点击导航区外、再次点击同一一级项、Esc 三种方式关闭。
- 键盘操作：Tab 进入导航栏，↑/↓ 循环移动焦点，Enter/Space 触发，Esc 关闭二级列并回到触发项。
- 动效：导航项过渡 0.2s `cubic-bezier(0.4,0,0.2,1)`；按下有一级项 0.97、二级项 0.985 缩放反馈；切换一级项时二级项按 18ms 逐项延迟滑入淡入。
- 直接访问二级路由（刷新或外部链接）时，所属一级项自动保持选中并展开对应二级列。
- 系统管理下「组织架构」「企业成员」「角色管理」「企业中心」为真实页面，其余 2 个二级项指向占位页，模块定稿后替换。

### 5.8 告警中心（PAGE-01）

- 页面结构自上而下：查询条件区 → 列表容器；本期范围为「告警展示 + 清理 + 导出」，**无页面标题区、无通知规则区**。
- **导航**：告警中心为一级菜单入口，点击直接进入页面，**不展开二级导航栏**；该模块不设二级功能页。
- 数据链路：设备先在本地触发报警并上报云端，云端再推送到本系统，**一条推送即一条告警，不做合并去重**。
- 查询条件区为「标签在上、控件在下」的四项等宽布局，条件行底部对齐：告警时间（**日期区间选择器，默认今日**，预设「今日 / 近 7 天 / 近 30 天」，跨度上限 12 个月、不可清空）、事件类型（按类别分组多选）、所属用能单元（含下级语义）、所属设备（按**设备名称 / License** 模糊匹配，按编号不匹配）。
- **「查询」「重置」「导出」三个按钮与四个条件项同处一行**（贴行尾、与控件底部对齐）：视口宽 ≥ 1280px 时同行，更窄时按钮组整体换到下一行并保持右对齐、条件项仍等宽；768px 以下每个条件项独占一行。
- **没有单独的刷新按钮**——重新点「查询」、点「重置」，或直接刷新网页即可获取最新数据。
- 列表 7 列：选择框、告警时间（日期 / 时刻**两行**展示）、所属用能单元、所属设备（设备名称 + `License：{License}`）、事件类型（浅底主色标签）、告警内容、操作；**全列定宽合计 1096px、不固定两侧列**，操作列紧随内容列；分页入口常显，默认 **10 条/页**，可选 10 / 20 / 50 / 100。
- 默认按**告警时间降序**（最新在最上方）；仅「告警时间」一列可排序，**点击列头在「降序 ⇄ 升序」两态间切换，不提供「取消排序」**，排序图标常显并提示下一次点击的方向；点「重置」后回到降序。
- 列表**不含**告警等级、重复次数、告警编号、处理状态与详情入口；告警编号仅作内部标识与导出字段保留。
- 设备 License 使用等宽字体，便于逐位核对。
- **跨页勾选**：勾选按告警标识记录，翻页或调整查询条件后仍保留；勾选后列表上方出现选择态操作条，展示「已选择 N 条告警」并提供「批量删除」与「取消选择」。
- **批量删除**：**不设单次条数上限**；确认弹窗明示「已选择 N 条告警」（含其他页的选择时追加标注）与不可恢复；取消时保留勾选。
- **单条删除**：行内「删除」打开二次确认弹窗，展示事件类型、告警时间、告警内容、设备名称与所属用能单元；删除后停留在当前页，当前页因此变空时回退到上一页。
- **导出**：按当前查询结果生成 CSV（字段为告警编号、告警时间、所属用能单元、设备名称、设备编号、设备 License、事件类型、告警内容），单次上限 10000 条；结果为空或超限时阻止导出并提示。
- 权限：页面进入由 `alarm` 权限点判定（无权限时整页展示空态与「返回」，不渲染查询区与列表）；删除（含批量）需 `alarm:delete`、导出需 `alarm:export`，无权限时对应入口不渲染、复选框不可勾选（可用 README 第四节中的运维工程师账号验证）。
- 事件类型字典共 **38 项**（温度类 1 + 相序与不平衡 5 + 需量与功率 3 + 防窃电 2 + A/B/C 相事件各 9），与 PRD 6.4 一致；演示数据覆盖全部事件类型。
- 告警的所属用能单元路径取自「系统管理 › 组织架构」中维护的用能单元节点，两个模块数据一致。

### 5.9 企业成员（PAGE-01，系统管理 · 企业成员）

- 页面纵向三区：标题区（标题 + 说明 + 右侧「新增成员」）→ 筛选区卡片（搜索 + 角色 / 状态 / 组织节点四项等宽 + 行尾「查询」「重置」）→ 列表卡片（表格、分页）；成员列表有 7 列信息，取消 960px 居中限制，占满内容区可用宽度。
- 列表字段：姓名、账号（原值，不脱敏 + 账号类型）、角色、数据范围、状态、更新时间、操作；首列为纯文本姓名，**不展示成员头像**（Q-IXD-MEM-01）。
- 表格列宽全列定宽（合计 1290px）、不固定两侧列；窄屏（1366px）下表格内部横向滚动，页面整体不出现横向滚动。
- 筛选条件之间为「与」，同条件多选为「或」；角色筛选选项标注各角色成员数；组织节点筛选范围为「所选节点及其全部下级」；**条件填好后点「查询」生效**（非即时过滤）。筛选条件不做跨会话保留，刷新后回到默认（无筛选、第 1 页），Q-IXD-MEM-02。
- 企业超级管理员默认置顶并以主色浅底标签标识；角色多于 2 个时展示前 2 个 + `+N`，悬停可看全部；成员失去全部角色时角色列以警告色展示「无角色」。
- 数据范围列展示「全部数据 / N 个组织节点 / 未设置」；**「N 个组织节点」可点击打开「数据范围详情」浮层**（OVERLAY-06，按层级路径逐条列出全部节点并支持按名称/路径筛选）；未绑定节点时以警告色展示「未设置」并提示无法查看任何业务数据（PRD Q-MEM-07）；数据范围含已被删除的节点时附注「部分组织节点已失效，请重新选择」。
- 状态列：**以开关（`a-switch`）直接控制启用 / 停用**，关闭开关弹二次确认、打开开关直接生效；无 `system:member:toggle` 权限时降级为只读文字；初始密码未修改时附注「待改密」；账号处于登录失败锁定时附注「已锁定（剩余 X 分钟）」；**已停用成员不再展示锁定附注**（停用优先）。
- 行操作列为「重置密码 / 编辑 / 删除」三个内联文字按钮，按权限点逐项渲染；删除为危险色，最后一名超管与当前登录账号的删除按钮置灰。
- 新增成员：表单按「基础信息 → 账号与密码 → 权限配置」三段分组（姓名、账号、初始密码、确认密码、角色、数据范围）；**账号不提供类型切换，由输入内容自动识别**（含字母或 `@` 视为邮箱）；创建成功后切到**结果态一次性展示账号标识与初始密码**并提供复制，未点过复制就关闭时用 `a-popconfirm` 拦截（PRD Q-MEM-01）。
- 账号复用认证模块的账号输入组件（手机号含国际区号、邮箱自动识别）。**账号标识提示按四种状态互斥展示（同一时刻仅一条）**：格式非法 → 红字格式错误；**本企业已有该成员** → 红字「该成员已存在，请勿重复添加」；**账号在平台已存在但本企业没有** → 进入「加入企业」绿色一行式提示「该账号已存在于平台，将沿用其现有密码」并**隐藏初始密码/确认密码**；其余情况 → 灰色提示「账号在平台内唯一；已存在的账号可直接加入本企业」（仅新增态展示，编辑态不展示）。
- **加入企业（免密）**：新增成员时若账号标识在平台已存在，不要求设置密码、沿用该账号的平台级密码，结果态不展示密码行；该账号因此加入本企业并可在登录时选择进入；新建账号仍由管理员设置初始密码并标记「待改密」。
- 初始密码由管理员设置（需达密码强度「中」及以上，复用 `PasswordStrength` 组件实时反馈）；成员首次登录强制改密，列表以「待改密」标识提示管理员跟进。
- 编辑成员：不出现密码字段（密码变更走「重置密码」），不出现成员状态（状态变更走启停用）；账号标识变更时同步平台账号（新标识可登录、旧标识失效），改成本企业其他成员或平台其他账号的标识时拦截并提示「该账号已存在于平台，请更换账号标识」；角色或数据范围发生变化时展示变更影响提示。
- **成员为企业超级管理员时，数据范围字段只读并展示「全部数据」**（PRD Q-MEM-08），不渲染组织节点选择入口。
- 数据范围选择组件（`MemberScopeSelect.vue`）：弹窗内以复选树展示企业根节点与全部组织节点（**用能单元不作为可选范围**）；父子节点同时选中时按父节点去重；单成员上限 100 个节点，超出时阻止继续勾选；未选择节点时允许确定但持续展示警告。
- 停用成员：二次确认弹窗展示成员信息与影响说明；**停用只作用于本企业**——该账号在其他企业的归属与登录不受影响，且停用后不再出现在该账号登录时的「选择登录企业」列表；停用本人时额外提示「停用后你本人也会被退出登录」并执行退出登录。
- 删除成员：二次确认弹窗**逐条列出三条风险说明**（不可恢复、清空组织架构节点负责人引用、历史操作记录保留），并要求**勾选「我已了解删除后不可恢复」**后「确认删除」才可用；删除后同步清空组织架构中该成员的节点负责人引用（PRD F-MEM-08 业务结果）。**删除只移除该账号在本企业的归属**，账号本身与其在其他企业的归属、登录不受影响。
- 重置密码：新密码由系统随机生成，结果态一次性展示；重置同时解除该成员的登录失败锁定；**新密码写入该账号的平台级密码，在该账号的所有企业下同时生效**；已停用成员的重置密码按钮置灰。
- 超级管理员保护：最后一名超管的状态开关与「删除」按钮置为禁用并在悬停时说明原因；编辑时移除其超管角色会被拦截并提示「企业需至少保留 1 名超级管理员」（PRD Q-MEM-05）。
- 不能删除当前登录账号，该行「删除」按钮置灰并在悬停时说明原因。
- 权限：入口按当前账号的功能权限点显隐（会话账号 → 企业成员 → 角色 → 权限点并集）；可用「运维工程师」等非管理员账号登录验证「无权限则入口不渲染」的表现。
- 所有成员与权限变更（新增、编辑、账号变更、角色变更、数据范围变更、启停用、删除、重置密码）均写入变更记录容器，对应 PRD F-MEM-09（正式查看入口为「系统管理 › 系统日志」），页面上不做额外提示，日志中不含密码内容。
- 演示入口：页面底部提供「模拟列表加载失败」「模拟账号锁定」与「模拟加入企业账号」三个快捷按钮，依次用于验证错误态、锁定附注，以及一键预填一个「仅归属其他企业、本企业没有」的账号（`+8613880013888`）以查看「加入企业」绿色提示与隐藏密码字段。

### 5.10 角色管理（PAGE-01，系统管理 · 角色管理）

- 左右分栏：左侧角色列表面板（宽 280px，窄屏 240px）+ 右侧权限配置面板（自适应，最小 560px）；权限配置区信息密度高，取消 960px 居中限制，占满内容区可用宽度。
- 左侧角色列表：搜索框（宽 100%）+ 列表 + 底部「新增角色」按钮；列表项展示角色名称、类型标签与成员数，权限为空的角色附「待配置权限」警示标签（**不展示角色描述**，描述在右侧面板头部下方呈现）。
- 角色列表排序：预置角色置顶，自定义角色按创建时间倒序；默认选中第一个角色（预置角色），右侧即时展示其权限配置，形成「左选右配」联动。
- 预置角色（企业超级管理员）：名称后附锁定图标，**不渲染「重命名」与「删除」入口**（入口不出现而非置灰）；权限全选且勾选框不可取消，不展示「全选 / 清空」与「取消 / 保存」；面板内展示只读说明。
- 右侧权限面板为纵向弹性结构：面板头部（类型图标 + 角色名称 + 类型标签 + 成员数 + 「编辑」）→ 权限工具行（权限搜索 + 已选统计 + 全选 / 清空）→ 权限配置区（吸收剩余高度）→ 底部操作区（未保存摘要 + 取消 / 保存）。
- **权限配置区为分区平铺（非折叠树）**：按「目录行 → 菜单卡片 → 按钮勾选项」逐级展开，**层级与平台导航一一对应**——目录级为一级导航栏内的项、菜单级为二级及更深菜单栏内的项、按钮级为页面内操作；**菜单卡片为递归组件**，菜单下若还有下级菜单（如「设备用电管控 › 负荷策略」），下级菜单卡片**嵌套在上级菜单卡片内部**（每级右移 16px、底色转浅 `#fcfdfd`、附 2px 主色浅色左边条），层级归属一眼可辨、深度不受限制。
- 权限点按 PRD 7.4 权限点字典渲染，共 **47 项可授权能力**（工作台 1 + 点位地图 1 + 告警中心 3 + 设备管理 · 设备台账 6 + 设备管理 · 设备OTA 5 + 设备管理 · 设备用电管控 › 负荷策略 7 + 组织架构 7 + 企业成员 8 + 角色管理 5 + 企业中心 4；按层级拆解为 3 个自身即页面的目录 + 7 个菜单进入能力 + 37 个按钮级权限点）；目录行与菜单卡片行头右侧展示该层级的已选计数。
- **每一级都可独立授权**：目录标识代表整棵子树（勾选 = 整块授权其下全部功能），其下还有下级菜单的菜单标识（如 `device:power`）同样代表整棵子树，页面菜单标识仅代表「可进入该页面」，按钮标识为最小颗粒度；**页面菜单级节点自带「可进入该页面」语义**，不再有独立的「查看 XX」权限点。
- 勾选联动：勾选任一按钮级权限点会自动补齐其所属菜单的进入能力；取消整目录授权时其下全部按钮一并取消，避免出现「能操作但进不去」的矛盾组合；目录与菜单行均呈全选 / 半选 / 未选三态。由此「只勾菜单、不勾按钮」成为合法的**只读进入**配置。
- **权限修改为草稿态**：勾选变化不即时生效，底部展示未保存摘要（`已选 N / 共 M · 新增 X 项 · 移除 Y 项`）与「取消 / 保存」；无变更时「保存」不可用（PRD Q-ROL-04）。
- 保存权限：先弹出**差异确认弹窗**，逐项列出新增与移除的权限点（超过 10 项时列表内部滚动），存在移除项时展示受影响成员数；取消后**保留勾选状态**可继续编辑。
- 未保存保护：存在未保存修改时切换角色、离开页面（路由跳转）都会被拦截，分别提供「放弃修改 / 继续编辑」与「放弃修改并离开 / 留在此页」两个明确动作（EX-ROL-04、EX-ROL-05）。
- 权限搜索：按**权限点路径文本**（如 `系统管理 / 企业成员 / 重置密码`）匹配，命中项关键字高亮、未命中节点淡化（`opacity: 0.45`）但**保持可见**（避免误认为权限点不存在），展示「命中 N 项」，且不改变任何勾选状态；清空搜索后淡化解除。
- 新增角色：弹窗只收角色名称与描述（**名称与权限分两步保存**，PRD Q-ROL-06），创建成功后新角色自动选中并进入权限面板（全未选），由管理员继续勾选并保存；名称企业内唯一（不区分大小写）。
- 删除角色：成员数为 0 时才可删除；「删除」项恒为可用，成员数非 0 时点击后提示成员数并阻断（不打开确认弹窗），不提供「先解绑再删除」的一键操作（PRD Q-ROL-02）；二次确认弹窗回显角色权限点数量与影响说明。
- 角色成员清单（OVERLAY-05）：只读浮层，展示该角色下的成员（姓名 / 账号 / 成员状态 / 数据范围，账号按原值展示不脱敏），支持搜索与分页；点击成员跳转企业成员页并携带角色筛选，企业成员页对应成员行以浅底 + 左侧主色标记高亮定位。
- 权限点生效链路：当前账号的功能权限 = 其绑定角色权限点的并集（会话账号 → 企业成员 → 角色 → 权限点）；可用「运维工程师」等非管理员账号登录验证「无权限则入口不渲染」的表现。
- 权限点字典抽为模块内常量（`modules/role/mock/permissions.ts`），供权限配置区渲染与后续模块回填；新增模块只需追加常量并同步 PRD 7.4 字典（含告警中心的 `alarm` / `alarm:export` / `alarm:delete`）。
- 所有角色与权限变更（新增、重命名、删除、权限配置）均写入变更记录容器，对应 PRD F-ROL-09（正式查看入口为「系统管理 › 系统日志」），权限变更逐项记录新增与移除的权限点，页面上不做额外提示。
- 演示入口：页面底部提供「模拟列表加载失败」「模拟权限加载失败」「模拟权限字典更新」三个快捷按钮，用于验证错误态与权限字典更新提示。

### 5.11 组织架构（PAGE-01，系统管理 · 组织架构）

- 左右分栏：左侧层级树面板（宽 360px，窄屏 280px）+ 右侧属性面板（自适应，最小 480px）；结构维护页信息密度高，取消业务页通用的 960px 居中限制，占满内容区可用宽度。
- 结构维护入口全部收在树节点行右侧：页面标题区与树工具行不放置「新增下级」或「全部展开 / 收起」按钮；树工具行仅保留搜索框。
- 右侧面板上下分区：上方为所选节点属性（两列网格：短字段并排、层级路径 / 详细地址 / 备注等长字段跨两列；单列落空的字段自动跨列，不留空网格块），下方为该节点及其全部下级的用能单元列表（字段：名称、用能单元编码、GPS 坐标、所属组织节点全路径；长文本折行完整展示不省略，名称可点击定位到左侧树，列表内按名称/编码筛选）。
- 右侧面板为纵向弹性布局：属性区按内容高度、用能单元卡片吸收剩余高度（`min-height: 280px`），卡片带浅底与描边自成一区，避免「上重下轻 + 底部大片留白」。
- 用能单元列表默认每页 20 条，可分页切换 10 / 20 / 50 / 100 条/页，分页入口常显（不因只有一页而隐藏）并锚定在卡片底部；列宽按比例分配（16% / 20% / 26% / 剩余），避免仅末列吸收全部剩余宽度导致右侧大片空白。
- 树区覆盖加载中、有结构、仅根节点的空结构、搜索命中、搜索无结果、加载失败六种状态；搜索命中列表展示命中名称与上级路径，点击可定位并展开路径。
- 加载失败与搜索无结果使用自研紧凑状态块（44px 圆形图标 + 14px 单行标题 + 12px 说明 + 可选操作按钮），不使用 `a-result` / `a-empty` 的默认大尺寸（树面板仅 360px 宽，大图标与大标题会把文案挤成两行）。
- 结构维护：新增下级（组织节点 / 用能单元）、重命名、移动（调整上级）、同级排序（上移 / 下移）、删除（二次确认）。
- 节点类型用图标区分：企业根节点 `BankOutlined`（主色）、组织节点 `ApartmentOutlined`、用能单元 `ThunderboltOutlined`（`#faad14`）。
- 企业根节点在本页完全只读：不展示「更多」操作区与属性面板「编辑」/「重命名」，属性面板仅展示层级路径、下级节点数量、备注三项（不展示负责人、GPS 坐标、详细地址与创建时间），仅可新增下级；选中根节点可正常查看属性。
- 用能单元为叶子节点，不展示「新增下级」入口与展开箭头；新建用能单元时自动生成「用能单元编码」。
- 节点名称同级唯一；同名时阻止保存并提示「同级下已存在同名节点，请修改名称」。
- 树区视觉按交互文档 3.1 / 4.1.2 落地：节点行高 32px、每级缩进 16px、选中底色 `#ecf4f3` 配主色文字、悬停底色 `#f5f7fa`；长节点名称逐层 `min-width: 0` 单行省略，保证右侧操作区不被裁切。

- **触发方式两类**：①**时控**——周期类型「按日 / 按周 / 一次性」三选一（按周选星期、一次性选执行日期），再配若干「时间（HH:mm）+ 动作（拉闸 / 合闸）」时间点条目（1-20 条，按时间升序自动排列，时间与动作完全相同者拦截；浮层内固定说明「按自然日判断、不跨日顺延」的跨日口径）；②**负控**——以**「事件 + 动作」成对配置**触发规则（1-10 条，每条 = 触发事件 + 命中后执行的动作 `拉闸` / `合闸`，**同一事件只能配置一条规则**），触发事件取自**告警中心的事件类型字典（38 项，按类别分组、可搜索）**，并配**单一「执行延时」**（0-60 整数分钟，默认 0 立即执行）；**不依赖「条件解除」信号**，需恢复供电时由用户另配一条「对应事件 → 合闸」规则。
- **作用对象配置**：作用用电单元**必选**（树形多选，**仅用能单元可勾选**，组织节点只作路径展示、勾选框禁用）；作用设备选填（多选，选项**仅限已选作用用电单元下的设备**，候选项按所属用能单元分组）。**留空表示作用于所选用电单元下的全部设备，为动态范围**（后续新增设备自动纳入）；**非空为静态清单**（后续新增设备不自动纳入）。浮层内以固定文案区分两种范围语义，并在作用对象汇总条实时回显 `{N} 个单元 · {M} 个设备`（含待接入 / 离线台数提示）；取消某用能单元时自动移出该单元下已选设备并提示移出台数。
- **生效期与备注**：生效开始日期必填（默认当日）、结束日期选填（结束日期留空展示 `长期有效`，不早于开始日期）；备注选填、最多 200 字，二者同一区块内先后排列。
- **新建 / 编辑策略**（OVERLAY-01 共用）：编辑态回填现有配置并展示创建信息；按触发方式动态呈现配置区，**切换触发方式或周期类型时就地提示（切换确认提示条）并二次确认**，确认后清空原触发配置（取消则回退取值）；保存前统一经过 OVERLAY-02。
- **保存确认**（OVERLAY-02）：**复述完整配置而非差异**（策略名称、触发方式、周期与动作 / 触发规则、**作用对象计数 `{N} 个单元 · {M} 个设备`**、作用用电单元路径、生效期），并固定展示拉闸风险提示条（红底）；同一时间点同时含拉闸与合闸时追加「按拉闸优先执行」提示（不阻止保存）；「返回修改」回到 OVERLAY-01 且已填内容不丢失。

- **启用 / 停用**：状态列开关**停用需二次确认、启用直接生效**（与设备台账、企业成员口径一致）；停用确认明示「停用后不再自动拉合闸，已在执行中的批次不受影响」；**该策略存在已拉闸且未合闸设备时，停用与删除的确认弹窗均追加**「该策略当前有设备处于已拉闸状态，停用 / 删除后不会自动合闸，请确认现场送电方式」（演示数据中 DEV-0002 即该样本）。

- **多策略冲突裁决（拉闸优先）**：仅「启用」且「生效中」的策略参与；任一策略要求拉闸则最终动作拉闸，合闸只在**全部**拉闸条件解除后下发；同一策略同一时间点同时含拉闸与合闸按拉闸优先；**本期不做保存期冲突拦截**，允许范围重叠；规则为平台固定、企业不可配置。
- 权限：页面进入由 `device:power:strategy` 判定（无权限时整页展示空态与「返回」，不渲染查询区与列表）；新建 `device:power:strategy:create`、编辑 `:edit`、启用停用 `:toggle`、删除 `:delete`、查看执行记录 `:record` 逐项按权限点渲染入口，无权限时不渲染（状态开关无 `:toggle` 时 `disabled` 并由文字承载状态）；仅具备页面权限时为只读查看（**可用 README 第四节中的「只读查看」角色验证，该角色默认授予 `:record`**）。配置自动拉合闸的权限与设备详情页的人工即时控制（`device:ledger:control:switchon` / `:switchoff`）**分开授权**。
- 所有策略变更（新建、编辑、启停用、删除）与每次执行的触发结果均写入变更记录容器（正式查看入口为「系统管理 › 系统日志」），页面上不做额外提示。
- 演示入口：页面底部提供「模拟加载失败」与「模拟策略触发」（对首个生效中的时控策略按其首个时间点动作触发一次，用于验证执行记录与「拉闸优先」裁决）两个快捷按钮。

### 5.18 系统日志（PAGE-01，系统管理 · 系统日志）

- 页面结构：**留存周期 Warning Alert 置顶常驻**（无页面标题区）+ **日志类型页签** + 筛选区 + 列表区（分页位于区内底部）；内容容器**撑满内容区**；筛选区与列表区为独立白底容器。
- **单页双页签**：「登录日志」与「操作行为日志」；默认落在**登录日志**；切换页签**复用该页签上次的查询结果与页码、不重复查询**，首次进入该页签时才按默认条件加载；两个页签的查询条件各自保留。
- **查询为提交式**：修改时间范围或筛选项仅改草稿条件，点「查询」后才生效；「重置」恢复默认条件（**当日**、其余为空）并立即查询。
- 登录日志：记录当前登录账号在当前企业内的**会话行为** —— **登录（成功 / 失败 / 已锁定）与退出登录**；列为操作时间、操作类型、操作账号（**账号在上、姓名在下**）、登录方式、结果、失败原因、来源 IP、来源终端（共 8 列，`scroll.x = 1058`）；退出登录记录的登录方式与失败原因展示 `—`；**不含「进入企业」**（账号不可见其他企业数据）；来源终端**仅「浏览器 / 操作系统」**；账号与来源 IP 按**原值展示**（内部审计视图，不脱敏）；**为纯只读清单，行不可点击、不提供「查看详情」**。
- 操作行为日志：覆盖 **8 个已定稿模块**（组织架构、企业成员、角色管理、企业中心、设备台账、设备OTA、负荷策略、告警中心）的变更类动作；列为操作时间、操作账号（账号在上、姓名在下）、所属模块、功能、变更类型、操作对象、变更内容摘要、操作（共 8 列，`scroll.x = 1058`）；**保留查看详情**（「操作」列按钮 + **整行可点击**）。
- 筛选：**时间范围**（必填、**默认当日**、单次跨度 ≤ 90 天、提供「今日 / 近 7 天 / 近 30 天」快捷区间）；登录日志另有账号、**操作类型**（多选：登录 / 退出登录）、登录方式（多选）、结果（多选）；操作行为日志另有操作账号、所属模块、功能、变更类型、关键字。各条件项**等宽等分**并与「查询」「重置」「导出」按钮组同排；**「所属模块 → 功能 → 变更类型」三级联动收敛**，切换模块时不属于新模块的功能与变更类型自动清空。
- **详情抽屉**（OVERLAY-01，宽 640px，只读，**仅操作行为日志**）：展示「基本信息 + 变更明细」，变更明细按变更类型呈现**五类形态** —— 字段级前后值表 / 权限点增删清单（新增与移除分列、含所属模块与页面路径）/ 状态变更条（原状态 → 新状态）/ 归属变更条（原归属 → 新归属）/ 对象清单表（批量与执行类，超 200 条时顶部说明总数并引导导出）；企业名称变更类记录追加**同步影响说明**。抽屉**除「关闭」外无任何可提交控件**，不提供复制 / 导出 / 跳转业务页 / 编辑 / 删除。
- **导出**：入口位于**筛选区「查询」「重置」之后**，严格等于当前查询条件，导出行数上限 10000 行（超限阻止并提示缩小范围、不截断）；两类日志的导出权限**相互独立**（`system:log:login:export` / `system:log:operation:export`），无权限时不渲染入口且不做提示。
- **页面只读**：无行选择框、无批量操作、无编辑 / 删除 / 补录入口；表格固定按操作时间倒序、不提供排序切换；列表内**不设工具行**（原记录条数统计已移除，总数由分页区展示）。
- **表格列宽与间距**：表头与单元格内边距统一 14px，列间距均匀；短字段（时间 / 操作类型 / 操作账号 / 登录方式 / 结果 / 来源 IP）不换行不截断，长内容（失败原因 / 来源终端 / 操作对象 / 变更内容摘要）单行省略并支持鼠标悬浮查看全文。
- **对象快照与已删除标注**：日志以写入时固化的账号姓名与对象名称展示；对象已被删除时表格与抽屉均标注「已删除」。
- 权限：进入需 `system:log`（两类日志的查看**共用该菜单级标识**）；无 `system:log` 时整页展示无权限空态。
- 状态与异常覆盖：加载中、有数据、查询中、空数据（含留存期外说明）、列表加载失败、时间范围校验失败（未选 / 跨度超限 / 起止倒置）、导出中 / 导出失败 / 超上限拦截、详情打开 / 详情加载失败、记录已归档、无权限、无导出权限。
- 演示入口：「原型演示提示」条提供「模拟加载失败」「模拟详情加载失败」（仅操作行为日志页签展示）与「重置演示数据」，便于复现错误态与反复走查。
- 演示数据：登录日志含 **12 条今日记录**（覆盖三种登录方式、三类结果与退出登录，使默认「当日」范围下始终有数据）与非今日记录若干；操作行为日志含 20 条预置记录（覆盖 8 个模块与五类变更明细形态，含一条对象已删除的「删除角色」与一条含**同步影响**的企业名称变更）。**原型内新产生的会话记录**（登录页、选择登录企业页与顶栏退出登录在判定结果后写入）会与预置数据合并展示。

| 点位地图 | 本模块**不维护任何演示数据**：用能单元取自组织架构、设备取自设备台账的演示容器，模块内只做加工与呈现（`modules/location/store/location.ts`）。地图为**原型内模拟地图**（`LocationView.vue` 内的自绘画布）：坐标按可视范围线性换算、网格与道路示意为绘制元素，**不接入第三方地图服务**；缩放 / 平移 / 重置视野 / 检索 / 筛选 / 下钻均为前端计算，不代表真实地图性能；标记渲染上限 500 与提示条为原型口径。权限点 `location` 已登记入权限点字典（PRD v0.1），该次新增使字典规模由 33 项增至 34 项（设备OTA 新增 2 个按钮级权限点后，当前字典规模为 **36 项**） |
| 用能单元编码 | 新建用能单元时按 `UNIT-{4 位序号}` 规则自动生成，仅用于原型演示，正式编码规则待定 |
| 响应式 | 按 PC 桌面端设计，最小支持 1366×768；1080px 以下隐藏左侧品牌区 |

重置演示数据：各页面底部「原型演示提示」中点击「重置演示数据」，或清理 localStorage。

### 7.2 组织约定

| 约定 | 说明 |
|------|------|
| 模块垂直切分 | 每个业务模块在 `src/modules/{模块名}/` 下自带 `pages/components/store/mock/utils`，模块内文件互不越界 |
| 新增模块 | 新增一个模块 = 新增一个 `modules/{模块名}/` 目录 + 一个 `router/modules/{模块名}.ts` 路由文件，并在 `router/index.ts` 的 routes 中加入 |
| 跨模块共享 | 两个及以上模块使用的组件、字典、工具才放 `src/shared/`，否则留在模块内 |
| 状态管理 | 模块状态放在模块自己的 `store/`，统一从 `store/index.ts` 引入；未引入 Pinia，跨页面状态用 `reactive` 单例 |
| 后台页面 | 需要顶栏与导航的业务页面挂载在 `AdminLayout` 下（见 `router/modules/dashboard.ts`），页面内容使用 `.page-container` 居中容器 |
| 导航挂载 | 一级导航项在 `AdminLayout.vue` 的 `mainNav`（业务域组）与 `bottomNav`（系统组）中集中配置：仅有一级项 `route` 时点击直接进入页面（如「告警中心」），有一级项 `children` 时展开二级导航列（如「系统管理」「设备管理」）；模块开工时补齐一级项的 `route` 或 `children`，并在 `router/modules/dashboard.ts` 增加对应路由 |
| 样式归属 | 全局重置放 `base.css`；共享组件放 `components.css`；模块样式按模块建文件并在 `main.ts` 注册 |
| 文件命名 | 页面以 `XxxView.vue` 结尾；组件以 `XxxYyy.vue` 命名；工具与状态使用小写文件名 |
| 路径别名 | 统一使用 `@/` 指向 `src/`，不写跨层相对路径 |

### 7.3 新增模块步骤

1. 建目录 `src/modules/{模块名}/`，按需建 `pages/`、`components/`、`store/`、`mock/`。
2. 在 `src/router/modules/` 下新建路由文件，导出该模块的路由数组。
3. 在 `src/router/index.ts` 引入并加入 `routes`。
4. 如模块页面需后台顶栏，把路由挂在 `AdminLayout` 的 `children` 下。
5. 如有模块专属样式，在 `src/styles/` 下建文件并在 `main.ts` 引入。
6. 文档侧在 `docs/product/{序号}-{模块名}/` 建 PRD 与交互设计文档，并更新 `docs/product/README.md` 版本矩阵。
