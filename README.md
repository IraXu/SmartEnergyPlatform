# 智能数字化能源系统 — 原型

> 【重要】本原型仅用于产品交互验证，用于验证产品结构、任务流程、交互状态与关键文案，
> **不作为生产代码或研发实现方案**，不包含后端接口设计、数据库设计或字段类型定义。

***

## 二、启动方式

```bash
cd prototype
npm install
npm run dev
```

访问地址：<http://localhost:5173/>

类型检查与构建：

```bash
npm run build
```

| 平台管理端 | `admin@energyplatform.com`（平台超管）/ `zhangyy@energyplatform.com`（密码 `Platform2026`） | 账号**不属任何企业**，左侧为 首页 / 客户&设备 / 平台管理（权限管理 › 平台成员管理、平台角色管理） |
