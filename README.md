# 智能数字化能源系统 — 登录与注册 原型

> 【重要】本原型仅用于产品交互验证，用于验证产品结构、任务流程、交互状态与关键文案，
> **不作为生产代码或研发实现方案**，不包含后端接口设计、数据库设计或字段类型定义。

---

## 一、技术栈

| 依赖 | 版本 | 说明 |
|------|------|------|
| Vue | 3.5 | Composition API |
| TypeScript | 5.7 | 类型约束 |
| Vite | 6.0 | 开发与预览 |
| antdv-next | 1.5.4 | 组件库，文档站 antdv-next.com |
| @antdv-next/icons | 1.1.2 | 图标库 |
| vue-router | 4.5 | 多页面路由 |

---

## 二、启动方式

```bash
cd prototype
npm install
npm run dev
```

访问地址：http://localhost:5173/

类型检查：

```bash
npm run build
```
