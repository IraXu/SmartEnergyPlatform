# 智能数字化能源系统 — 原型

> 【重要】本原型仅用于产品交互验证，用于验证产品结构、任务流程、交互状态与关键文案，
> **不作为生产代码或研发实现方案**，不包含后端接口设计、数据库设计或字段类型定义。

***

| 依赖                | 版本    | 说明                     |

| Vue               | 3.5   | Composition API        |

| antdv-next        | 1.6.0 | 组件库，文档站 antdv-next.com |
| @antdv-next/icons | 1.1.2 | 图标库                    |

## 二、启动方式

```bash
cd prototype
npm install
npm run dev
```

访问地址：<http://localhost:5173/>

类型检查与构建：

```bash
npm run build
```
